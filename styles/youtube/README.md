# YouTube

YouTube の見た目を調整します。

## 機能

- 動画の再生が終わった後に出るおすすめ動画のグリッドを非表示にする
- ライブ配信でチャットを開いたままシアターモードにしても、動画を普通の動画と同じ横幅にする（チャットは動画の下に移す）
- 動画が画面の上に差しかかったら、スクロールに合わせて小さくしながら画面の左上に寄せて固定する

## 注意

- 小さくする機能は、スクロールに連動する CSS アニメーションとアンカー配置の両方に対応したブラウザでだけ動きます。対応していないブラウザでは通常の表示のままです。
- 小さくしているときは、プレビューのサムネイルや字幕の大きさなど、細かいところがずれることがあります。プログレスバーはクリックしてもシークせず（YouTube が元の大きさのバーで位置を計算するため）、再生位置のつまみも隠します。
- 自動再生のカウントダウンは消していません。
- 全画面で再生中に下へスクロールして出す動画一覧は、再生終了後以外は残しています。
- 動画の最後に投稿者が置く終了画面の要素（チャンネル登録ボタンや動画へのリンク）はそのままです。

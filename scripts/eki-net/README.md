# えきねっと

えきねっとの列車検索フォームに、前回検索した条件を自動で入力します。

## 対象ページ

- トップ（`/Personal/Top/Index`）
- 経路検索の条件入力（`/Personal/reserve/wb/RouteSearchConditionInput/Index`）

## 機能

- 「列車を検索する」で検索したときに、次の値を記憶する。2 つのページで同じ値を使う
  - 乗車駅・降車駅
  - 日付・時・分、出発／到着
  - 人数（おとな・こども）
- ページを開いたときに、記憶した値を入力する
  - 日付や人数は、選択肢にある値だけ入れる。過去の日付など選べない値は、サイトの既定のまま
  - 乗車駅か降車駅にすでに値が入っているときは、何も入力しない。サイト自身も同じセッションのあいだは経路検索ページに前回の条件を入れるので、それを残す

入力欄の名前は [fields.ts](fields.ts) にまとめています。

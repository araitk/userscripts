# Amazon

Amazon で、商品の価格の推移を見られるようにします。あわせて、短縮URLのコピーや、販売元を Amazon に絞り込むリンクも追加します。

## できること

### 商品ページ

右側の購入ボックスの下に、次のものを表示します。

- **短縮URL**: 余計な部分を省いた商品の URL（`https://www.amazon.co.jp/dp/…`）。クリックするとコピーします。
- **販売元をAmazonに限定**: 販売元を Amazon にして、商品ページを開き直します。
- **Keepa のグラフ**: 過去 1 年の価格の推移です。クリックすると Keepa で商品を開きます。

バリエーションを切り替えると、切り替えた商品の内容に変わります。

### 検索ページ

左側の絞り込み欄の一番上に「販売元をAmazonに限定」を表示します。クリックするとAmazon が販売する商品だけに絞り込みます。

### 再び購入ページ

商品をクリックして開く詳細で、購入ボタンの上に Keepa のグラフを表示します。

### 定期おトク便ページ

サブスクリプションの詳細で、右側に Keepa のグラフを表示します。

- amazon.in（「販売元をAmazonに限定」は表示しません）

## 表示の言語

リンクの文言は、サイトの表示言語に合わせます。対応している言語は次のとおりで、それ以外の言語では英語になります。

- 日本語
- 英語
- ドイツ語
- フランス語
- イタリア語
- スペイン語
- ポルトガル語
- オランダ語

## うまく表示されないとき

- Keepa に価格の記録がない商品では、グラフに「Sorry, no price history available.」と表示されます。
- Keepa のグラフ画像が読み込めないときは、グラフを表示しません。
- Amazon の画面の作りが変わると、表示されなくなることがあります。
